Examples
========

Please view our example notebooks directly on GitHub:

* `Bayesian inference of Non-stationary GEV parameters <https://github.com/Nischalcs50/nsEVDx/tree/master/examples/example_GEV.ipynb>`_
  : Fits a non-stationary GEV model with Bayesian inference and examines posterior parameter estimates.
* `Frequentist estimation of non-stationary GPD parameter and likelihood ratio test <https://github.com/Nischalcs50/nsEVDx/tree/master/examples/example_GPD_frequentist.ipynb>`_
  : Estimates non-stationary GPD parameters by maximum likelihood and tests whether covariates improve the model.
* `Generating random variates from non-stationary GEV <https://github.com/Nischalcs50/nsEVDx/tree/master/examples/example_generating_rv_from_nsEVD.ipynb>`_
  : Generates random observations from a non-stationary GEV model with time-varying parameters.
* `Bayesian metrics example <https://github.com/Nischalcs50/nsEVDx/tree/master/examples/example_bayesian_metrics.ipynb>`_
  : Calculates Bayesian diagnostics and summary metrics for fitted extreme-value models.
* `Quickstart example <https://github.com/Nischalcs50/nsEVDx/tree/master/examples/Quick_start_example.ipynb>`_
  Provides a short introduction to fitting and using the main nsEVDx model interfaces.
* `L-moments and GPD parameters example <https://github.com/Nischalcs50/nsEVDx/tree/master/examples/Lmoments_and_GPD_pars.ipynb>`_
  : Estimates GPD parameters with L-moments and illustrates threshold-exceedance analysis.
* `Nonstationary risk and return-period analysis with synthetic GEV data <https://github.com/Nischalcs50/nsEVDx/tree/master/examples/Nonstationary_risk_and_return_periods.ipynb>`_
  : Uses GEV data generated with ``NonStationaryEVD.ns_EVDrvs`` and an increasing
  time covariate to demonstrate design-life risk, reliability, first-exceedance
  probabilities, the Salas--Obeysekera return period, and posterior uncertainty
  bands for return-level and return-period plots.
